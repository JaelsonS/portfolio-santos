## Stack do site

| Camada | Tecnologia |
|--------|------------|
| Markup / CSS | HTML5, CSS próprio (sem Bootstrap) |
| Lógica | JavaScript (ES6+) |
| Fontes | Google Fonts — Sora + Manrope |
| i18n | `i18n.js` (PT / EN / ES + `?lang=`) |
| Contacto | Formspree |
